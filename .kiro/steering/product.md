# Product Overview

오늘의 운세 (Today's Fortune) - A simple, fun mobile fortune-telling app built with Granite and React Native.

## Core Features

- Daily random fortune messages in Korean
- Lucky number generation (1-100)
- Lucky color selection with visual display
- Fortune history tracking (stores last 20 entries)
- Clean, emoji-enhanced UI with smooth animations

## User Experience

The app provides a lighthearted, casual experience for users to check their daily fortune. The interface is simple and intuitive with a single-tap fortune generation and easy access to historical fortunes.

## URL Scheme

`fortune://fortune-teller`
